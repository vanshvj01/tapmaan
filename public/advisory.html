Monitor Forecast Hotspots Advisory Alerts Method

Advisory generation

The same forecast means different things to a farmer, a hospital and a ward officer. This turns the technical output into an advisory written for one audience, in one language.

    Severe warning. Held for meteorologist review and approval before it can be disseminated.

    Keeping generated text factual

    Where a language model drafts the advisory, it is given only the verified forecast figures and instructed to use no others. Any severe warning is flagged for expert approval before dissemination rather than released automatically. If the model is unreachable, a rule-based draft is produced instead, so the warning still goes out.

    Tapmaan is a student project built for use case KJS-CES-01, Climate Intelligence for Heatwave Monitoring, Prediction and Early Warning. Classification follows India Meteorological Department heatwave criteria. This is not an official warning service — for operational decisions, follow IMD.
